# 2.5.2 · 弹窗、键盘与表单可用性

整理日期：2026-09-18。2.5.1 已上线验证后继续改善日常操作，不新增云端权限或数据库结构。

## 改动

- 先用浏览器复现：通过键盘打开使用指南后，焦点仍留在背景入口。现在打开任一底部弹窗时，焦点进入关闭按钮，避免自动聚焦文字框弹出手机键盘。
- 弹窗具有可读标题、对话框语义和明确的关闭按钮名称。打开时背景主页面与下层弹窗不可交互；关闭后恢复。
- 嵌套窗口按实际打开顺序管理层级与 Escape，不依赖 HTML 的先后位置。关闭“复制餐厅信息”回到详情中的复制按钮，再关闭详情回到原卡片。
- Tab/Shift+Tab 留在当前弹窗的可用控件内；关闭返回各自入口，入口已消失时安全回到当前层或主操作。相册覆盖弹窗时同样隔离下层，关闭后恢复原照片入口。
- 原有未保存修改确认、照片处理中不能关闭、正式保存/草稿忙碌保护均保留，弹窗管理器不绕过这些规则。
- “添加这一顿的照片”和“合并导入本机备份”改为真正按钮，Enter/空格可打开文件选择；正在处理照片时禁用重复选择，云端账号仍禁止本机备份导入。
- 地址、标签、推荐菜、评价四个字段补齐关联标签，键盘焦点增加清晰边框。保留触摸操作、已有配色、手机输入字号及用户缩放。
- 新模块 `lib/dialogs.js`；资源版本 2.5.2，离线缓存 `our-food-map-shell-v10`。

## 验证进度

- 新增 5 项浏览器回归：打开/关闭焦点、嵌套复制、编辑放弃确认、照片与备份键盘选择器、相册返回下层、与 DOM 顺序相反的弹窗层级。
- 30 项 Node、45 项完整浏览器测试通过，共 75 项；发布自检覆盖 14 个前端模块、22 项离线资源。
- 真实双人云端完整回归通过，测试数据已清理、原有六表行数不变。2026-09-18 官方 npm registry 审计报告 0 个已知依赖漏洞。
- 正式发布/线上结果以 `PROJECT_LOG.md` 为准，待构建完成后补记。

边界：不是完整的无障碍认证。此次用 Chromium 浏览器检查键盘、语义和焦点行为；没有用所有手机或屏幕阅读器真机组合验证，也没有改变 Android 系统返回键行为。
